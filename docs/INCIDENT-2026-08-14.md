# Incident 14. 8. 2026 — a jak to bylo doopravdy

Doplňuje `docs/PREDANI-2026-08-14.md` z repozitáře `tessmickova/svetjmen`
(commit `ec4c235`). Ten dokument popsal incident správně, ale jeho hlavní
závěr byl **mylný** — a kdyby se podle něj postupovalo dál, dělala by se
zbytečně práce znovu.

## Co ten dokument tvrdil

> „Zdrojový kód živé verze nikdy nebyl na GitHubu.“

Vedlejší větev, na které celý vývoj probíhal, tím propadla.

Proto seděly i „záhadné“ nálezy: nasazení z 10.–13. 8. byly běhy CI z téhle
větve a sekce „Babiččina jména“ i „Stálice“ existovaly jen tady. Ověřeno:
živý web po rollbacku odpovídá commitu `dc4e8c1` z téhle větve.

**Nic se neztratilo a nic se nemuselo dělat znovu.**

## Co z toho plyne pro příště

1. **Před nasazením ověřit, že živá verze není novější než commit.** Tahle
   rada z původního dokumentu platí a je to ta hlavní pojistka:
   ```bash
   npx wrangler deployments list | head -20   # datum poslední živé verze
   git log -1 --format=%ci                    # datum posledního commitu
   ```
2. **Než prohlásím zdroják za ztracený, projít všechny větve všech
   repozitářů**, ne jen `main`:
   ```bash
   git ls-remote --heads <repo>          # co na dálku vůbec existuje
   git log --all --oneline -20           # co je po fetchi vidět lokálně
   ```
3. **Dva repozitáře pro jeden web jsou samy o sobě past.** ~~`svetjmen`
   i `profound-puppy-2b5fd3` obsahují Svět jmen; živý je ten druhý.~~
   **Vyřešeno 15. 8.:** historie i kód jsou sloučené v `tessmickova/svetjmen`
   a nasazovat smí jen ten — workflow má podmínku na název repozitáře.
   Postup a zbývající ruční kroky v [REPOZITAR.md](REPOZITAR.md).
