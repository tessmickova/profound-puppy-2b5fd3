# Dokumentace / Glosář

## Účel
Veřejná stránka s vysvětlením všech pojmů a měřítek používaných v aplikaci. Slouží jako vzdělávací zdroj pro uživatele.

## Soubor
`app/docs/page.tsx`

## Obsah stránky
Statický glosář pokrývající:

| Téma | Popis |
|------|-------|
| KP index | Stupnice 0–9, planetární geomagnetická aktivita |
| Bz | Severojižní složka meziplanetárního magnetického pole |
| Sluneční vítr | Rychlost, hustota, teplota |
| CME | Typy koronálních výronů hmoty, rychlosti |
| G-škála | G0–G5 geomagnetické bouře |
| Sluneční erupce | Třídy A–X |
| Lagrangeův bod L1 | Měřicí stanice DSCOVR/ACE |
| Magnetosféra | Ochranná bublina Země |
| Viditelnost v ČR | KP 0–8+ s popisy pro 50°N |
| Bortle škála | Světelné znečištění 1–9 |
| Měsíc | Fáze a vliv na pozorování |
| Tma oblohy | Občanský, námořní, astronomický soumrak |
| Tipy | Pozorování a focení polární záře |

## Jak rozšířit
- Nový pojem: přidat jako další sekci s nadpisem a popisem
- Je čistě statický — žádné API volání
